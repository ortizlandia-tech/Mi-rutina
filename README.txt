MI RUTINA - Android

Proyecto Android listo para compilar.
App offline con Rutinas A/B, temporizadores de trabajo, descansos automáticos, pausa, salto de ejercicio y visual humano animado.

APK local:
  gradle assembleDebug
Salida:
  app/build/outputs/apk/debug/app-debug.apk

También incluye .github/workflows/build-apk.yml para compilar automáticamente en GitHub Actions.
